## 🏗️ Terraform: Infrastructure, Defined

From a clear configuration to repeatable cloud foundations, Terraform makes infrastructure changes understandable and reviewable.

```hcl
terraform {
  required_version = ">= 1.0"
}

# Describe the infrastructure.
# Review the plan. Apply with confidence.
```
